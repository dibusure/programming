- [X] Пусть ты знаешь, что $$n = \prod_{i=1}^{k} p_{i}^{\alpha_i}$$, исходя от этого, найти $\sigma(n)$ — количество всех различных делителей числа, включая само число и единицу (МАТЕМАТИКОЙ)
  Кек, мы это делали уже. В общем, нам просто нужно k раз выбрать число от $0$ до $\alpha_i$: $\sigma(n) = \prod_{i=1}^k (1 + \alpha_i)$
  Проверим для чисел 13 и 36:
  1) У 13 всего два делителя, т.к. оно простое. $13 = 13^1 \Rightarrow \sigma(13) = (1+1) = 2$ — это 13 и 1, собственно. Сошлось
  2) У 36 делителей (не простых, а в целом) много. $36 = 2^2\cdot 3^2 \Rightarrow \sigma(36) = (1+2)^2 = 9$. Проверим етот факт петоном:
     #+BEGIN_SRC python :results output
def count_all_divisors(n):
    a = []
    for x in range (1,n+1):
        if n % x == 0:
            a.append(x)
    return len(a)

print(count_all_divisors(36))
     #+END_SRC
